# 谐振 · 鼠哥的个人主页

**[打开谐振 →](https://ndshuge.github.io/shuge-resonance/)**

一件可以弹的个人主页。几百根弦，每件作品一根，碰到就会响。

- **序**：一架扭转的竖琴，鼠标或手指横着划过就是扫弦。
- **第一乐章 · 造物**：53 件作品织成一座双曲面塔，滚动清单就是在弹它。
- **第二乐章 · 泛音**：点亮八个泛音，看它们叠成拨弦的那一下。
- **第三乐章 · 合奏**：往弦板上放乒乓球。
- **尾声 · 调音**：把一根弦调到 440 Hz，拍音消失时，一圈共鸣弦跟着响。

## 怎么做的

没有框架、没有图片、没有音频文件。

- 画面：原生 WebGL2，所有弦都是实例化的带状直线，振动按弦的本征模叠加计算。
- 声音：Karplus–Strong 拨弦合成，音准误差小于 0.1 音分；混响是现场生成的脉冲响应。
- 字体：思源宋体子集 + Bodoni Moda 斜体（SIL OFL 1.1，许可证见 `fonts/`）。

## 本地运行

```bash
node tools/serve.mjs . 18990
```
